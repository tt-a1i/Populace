# Contract: Fix asyncio.Event test isolation failure

## Goal
Fix 7 backend test failures (4 newspaper + 3 performance) caused by `asyncio.Event()` in `SimulationLoop.__init__` requiring an active event loop on Python 3.9, which fails when prior TestClient tests destroy the event loop.

## Acceptance Criteria

### AC-1: SimulationLoop lazy event creation
`SimulationLoop.__init__` must NOT call `asyncio.Event()`. The event must be created lazily on first use in async context.

### AC-2: SimulationLoop.start() still works
`start()` must create the event if not yet created and clear it before the loop begins.

### AC-3: SimulationLoop.stop() is safe without event
`stop()` must not raise if called before `start()` (when `_stop_event` is None).

### AC-4: All backend tests pass in full suite
`PYTHONPATH=. python3 -m pytest tests/ -q` must show 0 failures.

### AC-5: All frontend tests pass
`npx vitest run` must show 0 failures.

### AC-6: Frontend build succeeds
`npx vite build` must complete without errors.
